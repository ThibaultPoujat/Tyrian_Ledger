# Milestone Context - M20: Personal Learning and Investments

## User outcome

Tyrian Ledger learns which markets actually turn this user's capital efficiently
and can manage medium/long-term positions separately from short-term flips.

## Invariants

Polling observations are not exact fill timestamps unless source evidence says
so. Personal ranking influence needs sufficient sample/recency. Investments do
not imply guaranteed seasonal appreciation and do not corrupt realized flip
accounting.

## Exit

Personal evidence is an explainable ranking component and staged investment
positions/targets can be managed without a spreadsheet.

# Milestone Context - M21: Crafting Intelligence

## User outcome

The user can identify feasible profitable crafts using account capabilities,
owned/purchased inputs, opportunity cost, exact fees, and market evidence.

## Reuse

The historical M5 bounded recipe-graph design is useful reference material;
refresh external contracts before implementation.

## Invariants

Owned tradable materials are not free. Bound/unknown inputs explicit. Search is
bounded, cycle-safe, memoized. Theoretical craft margin without output
liquidity/history is not treated as guaranteed actionable profit.

## Review

Crafting economics/path tickets are R3 financial/product review work.

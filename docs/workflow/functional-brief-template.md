# Functional Brief Template

Use this template when asking Codex for a new feature or a material change.
Plain language is enough; leave technical design to Codex.

## Outcome

What should a Guild Wars 2 player be able to understand or do when this is
complete?

## Example

Give one realistic input and the result you expect to see or decide.

## Priority and trade-offs

What matters most: correctness, speed, less API usage, easier workflow,
privacy, visual clarity, or something else? State any trade-off you accept.

## Non-goals

What must not be added or changed?

## Acceptance check

How will you recognise that the feature is useful? A short observable check is
enough.

## Optional constraints

List any relevant Guild Wars 2 rule, design reference, budget, deadline, or
data/privacy constraint. Do not include an API key or other secret.

# Roadmap

| Phase | Outcome | Gate |
|---|---|---|
| M0 | External contracts and development runtime verified | No unknown critical dependency |
| M1 | Working local skeleton | Clean build + tests |
| M2 | Safe GW2 data gateway | Cached, throttled, fixture-tested data |
| M3 | Deterministic market engine | Correct copper/fees/depth/scoring |
| M4 | Useful desktop MVP | User can find and inspect opportunities |
| M5 | Account/crafting mode | Feasible and economic crafting analysis |
| M6 | Personal history | Realized profit is reproducible |
| M7 | Historical research | Local evidence without prediction claims |
| M8 | Release-ready local tool | Security, UX, performance, reproducible setup |

Do not skip M0. It contains the model/runtime and API validation gates.

# M13 - Local Runtime and Authenticated Read-Only Gateway

## Goal

Create the local ASP.NET Core runtime and secure read-only ArenaNet account/TP
access required by the personal product.

## Completion rule

The local app starts without a key behind tested loopback/Host/origin/request
boundaries, can safely validate a configured key, and has tested typed read-only
access to required personal TP endpoints without any secret entering React or
persistent data.

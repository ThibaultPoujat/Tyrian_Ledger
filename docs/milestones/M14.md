# M14 - Durable Personal Data

## Goal

Introduce reliable SQLite persistence, idempotent personal Trading Post sync,
and recovery controls before the local database becomes irreplaceable history.

## Ticket sequence

| Ticket | Scope | Depends on |
|---|---|---|
| [TKT-M14-01](M14/tickets/TKT-M14-01.md) | SQLite schema, migrations, repository boundaries, account/transaction/order/settings foundation. | M13-01, M13-03 |
| [TKT-M14-02](M14/tickets/TKT-M14-02.md) | Idempotent current/completed TP synchronization with partial-failure safety. | M13-03, M14-01 |
| [TKT-M14-03](M14/tickets/TKT-M14-03.md) | Local backup, restore, and clear-personal-data controls. | M14-02 |

## Completion rule

Repeated sync preserves trustworthy personal history without duplicates/data
loss, and the user has documented/tested local recovery and clearing controls.

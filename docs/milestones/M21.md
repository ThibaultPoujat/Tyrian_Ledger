# M21 - Crafting Intelligence

## Goal

Add practical crafting opportunity analysis after account, market-history, and
financial foundations are trustworthy.

## Ticket sequence

| Ticket | Scope | Depends on |
|---|---|---|
| [TKT-M21-01](M21/tickets/TKT-M21-01.md) | Read-only account inventory/material/crafting capability ingestion. | M13-02, M14-01 |
| [TKT-M21-02](M21/tickets/TKT-M21-02.md) | Owned-material opportunity cost, mixed-input crafting economics, exact fees/break-even. | M15-01, M21-01 |
| [TKT-M21-03](M21/tickets/TKT-M21-03.md) | Bounded recipe-path search and profitable-craft UI with liquidity/history evidence. | M19-01, M21-02 |

## Completion rule

Crafting opportunities use real economic input cost, feasibility, bounded graph
search, exact output fees, and market evidence; owned tradable materials are
never treated as free.

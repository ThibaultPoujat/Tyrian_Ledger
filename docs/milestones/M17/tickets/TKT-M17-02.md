# TKT-M17-02 - Add Order-Book Depth, Liquidity Quality, and Liquidity-Aware Sizing Evidence

GitHub issue: #80

## Milestone

M17 - Live Market Intelligence

## Goal

Distinguish genuinely tradable spreads from misleading top-of-book prices using
detailed order-book evidence.

## Functional outcome

Shortlisted candidates show whether intended quantity can realistically move
through visible depth, where price cliffs exist, and why shallow markets receive
smaller/negative liquidity treatment.

## Dependencies

TKT-M17-01.

## Recommended Codex configuration

Risk class: **R3 (financial/liquidity)**.

- Implementation: Terra High.
- Review path: **NORMAL** — independent Terra review subagent/check plus required tests/CI. No separate Sol review is a merge gate unless escalated under `docs/workflow/model-effort-guide.md`.

## Requirements

Reuse the order-book simulator for applicable execution-depth primitives and
calculate/expose:

- near-best quantity/listing depth;
- price impact for intended quantity;
- support gaps/price cliffs;
- depth-adjusted acquisition/liquidation evidence;
- shallow-market flags;
- liquidity participation cap/evidence for later sizing.

## Acceptance criteria

- [ ] One-unit top price cannot make empty market appear liquid.
- [ ] Deep-book, shallow-book, price-cliff, insufficient-depth tests.
- [ ] Intended quantity changes price-impact/depth evidence correctly.
- [ ] Existing simulator remains authoritative rather than duplicated.
- [ ] Liquidity reasons are exposed, not only hidden score.

## Validation

- Run deep-book, shallow-book, price-cliff, insufficient-depth, one-unit-top,
  and multiple intended-quantity simulator vectors.
- Run regression tests proving scanner results reuse the authoritative
  order-book simulator and expose liquidity reasons.
- Review integer-copper totals, overflow bounds, and deterministic ordering.

## Non-goals

Historical daily volume inference, personal fill learning, final portfolio size.

# TKT-M17-01 - Build the Live Fee-Aware Market Scanner

GitHub issue: #79

## Milestone

M17 - Live Market Intelligence

## Goal

Repurpose the public-market collector/analytics foundation into a live scanner
with exact fee-aware candidate economics.

## Functional outcome

The user can obtain current candidate markets with highest buy, lowest sell,
planned prices, exact fees, net profit/ROI, max allowed bid, freshness, and
configurable minimum filters without manual arithmetic.

## Dependencies

TKT-M13-01, TKT-M15-01.

## Recommended Codex configuration

Risk class: **R3 (financial)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Requirements

Use authoritative backend logic for:

- current aggregate prices;
- configurable bid/list policy;
- exact canonical fees;
- net profit/ROI;
- highest integer max bid meeting target policy;
- minimum ROI/absolute-profit filters;
- aggregate buy/sell quantity and freshness.

Reuse existing typed public gateway/collector/finance rather than parallel HTTP
or formulas.

## Acceptance criteria

- [ ] Fee-losing/negative scenarios rejected.
- [ ] ROI/max-bid integer-copper vectors include rounding edges.
- [ ] Min ROI and absolute-profit filters configurable.
- [ ] Results expose inclusion/exclusion reasons where useful.
- [ ] Scanner does not rank solely by raw ROI.
- [ ] Existing reusable collector/finance tests preserved/adapted.

## Non-goals

Historical persistence, personal weighting, final action screen.

## Delivery and review

Functional summary explains what current opportunity math is now automated.
Fresh flagship XHigh financial review required.

# TKT-M10-02 - Add Exact Browser Snapshot Recommendations

## Goal

Add a browser-side parser for the versioned static snapshot and an exact
`BigInt` recommendation engine whose results match shared C# golden vectors.
This ticket establishes mathematical parity before changing the user
experience.

## Dependencies

- TKT-M10-01 is merged and supplies the versioned snapshot contract and
  generator fixtures.

## Acceptance criteria

- Parse `market-snapshot.json` defensively in browser code, rejecting unknown
  incompatible versions, malformed required fields, unsafe numeric values, and
  incomplete snapshots before recommendations are calculated.
- Represent copper, quantities, fee intermediates, and recommendation
  calculations with `BigInt`; do not use JavaScript floating-point arithmetic
  for financial values.
- Preserve the existing recommendation policy, risk-profile behaviour, sorting,
  and deterministic tie handling unless an explicit later contract changes it.
- Add shared C# golden vectors that cover normal, boundary, high-value, fee,
  quantity, ordering, and no-recommendation cases, and verify browser results
  exactly against them.
- Keep parsing and calculation local: no browser network call to Guild Wars 2,
  `/api`, or a hidden service is introduced.
- Update VERIFY evidence when implementation or tests resolve a relevant
  external uncertainty; do not invent fee facts.

## Required tests and validation

- TypeScript unit tests for valid and invalid snapshot parsing, version checks,
  and `BigInt` conversion boundaries.
- Browser-engine tests consuming the shared golden vectors and asserting exact
  C# parity for every vector.
- C# tests that generate or verify the shared vectors from the authoritative
  deterministic engine.
- Run TypeScript checks, focused frontend tests, focused .NET tests, and
  `git diff --check`.

## Non-goals

- Replacing the React scan flow or deleting the hosted API.
- Publishing a snapshot or changing Pages workflows.
- Adding browser persistence beyond the existing local capital/risk preference
  scope.

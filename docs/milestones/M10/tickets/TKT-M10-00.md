## Acceptance criteria

- Add a new static-hosting ADR that explicitly supersedes only the local
  runtime assumptions in ADR-001 and ADR-002, while preserving the typed
  gateway, read-only, secrets, and integer-copper decisions.
- Record that the repository, history, Pages site, generated snapshot, and
  build artifacts are public deployment material. Define a public-history
  secret-audit gate before public release.
- Define the one-site, trusted selector-config workflow contract: same
  repository, reviewed config-only PR on `develop`, open code-PR immutable SHA,
  trusted validation, and `develop` fallback for invalid/closed/merged choices.
- Add the M10 milestone, context, ticket contracts, and navigation/manifest
  links without altering historical M9 records.
- Update relevant VERIFY entries, or add a narrowly scoped M10 VERIFY entry,
  for scheduled capture and deployment evidence. Keep batching, schema,
  rate-limit, retry, and fee facts explicitly unresolved where they are not
  externally verified.
- Document that the owner controls any actual GitHub repository-public,
  Pages-setting, release, and merge action. This ticket records the approved
  architecture; it does not perform those external state changes.

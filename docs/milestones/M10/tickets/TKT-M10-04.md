# TKT-M10-04 - Retire the Local Server Runtime

## Goal

Remove the local ASP.NET host and superseded persistence and integration-test
infrastructure after the static React experience is proven. Leave a coherent
single static build and generator toolchain without obsolete runtime paths.

## Dependencies

- TKT-M10-03 is merged and static browser tests cover the customer experience.

## Acceptance criteria

- Retire the ASP.NET host, local API endpoints, API integration tests, and the
  local two-process runtime scripts/configuration that no longer have a static
  equivalent.
- Retire SQLite-backed preference persistence, migrations, and related
  dependencies. Capital and risk remain intentionally browser-local, with no
  new remote persistence replacement.
- Remove obsolete developer, README, architecture, and test instructions while
  documenting the static build, local preview, and generator workflows that
  replace them.
- Preserve the typed gateway and domain engine only where the scheduled
  generator needs them; do not leave browser-accessible or unused server
  surfaces behind.
- Keep the snapshot contract, `BigInt` browser engine, accessibility coverage,
  and deterministic C# calculation tests working after the removal.
- Update relevant VERIFY entries and documentation references to reflect the
  implemented static architecture.

## Required tests and validation

- Run the complete remaining .NET test suite, TypeScript checks, frontend unit
  tests, static browser tests, and production static build.
- Search the shipped browser build and source for `/api`, ArenaNet hostnames,
  SQLite connection strings, migrations, and retired ASP.NET startup paths;
  investigate every remaining match.
- Perform a clean install/build or equivalent documented clean-environment
  validation and run `git diff --check`.

## Non-goals

- Publishing to Pages or changing GitHub repository settings.
- Replacing removed persistence with cloud storage, authentication, or a hosted
  backend.
- Changing the public snapshot schema or financial policy without a separate
  approved contract change.

## Required Codex configuration

Use **GPT-5.6 Terra with XHigh reasoning effort** and record that configuration

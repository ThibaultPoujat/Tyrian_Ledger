# TKT-M12-02 - Retire Static Pages Delivery and Browser Financial Duplication

GitHub issue: #67

## Milestone

M12 - Controlled Personal-Assistant Pivot

## Goal

Remove the obsolete active public-static runtime while preserving reusable C#,
React, testing, and security foundations for the local-first product.

## Functional outcome

The repository stops building/deploying the M10-M11 Pages application and stops
maintaining a second browser implementation of authoritative recommendation
math. Reusable market collection, gateway, analytics, and UI pieces remain
available for M13+.

## Dependencies

TKT-M12-01.

## Recommended Codex configuration

Risk class: **R2**.

- Implementation: Terra High or Sol High.
- Review: fresh Sol High.

## Scope

Retire/remove where they exist only for the superseded runtime:

- GitHub Pages publication workflow and Pages-only scripts/config;
- external Pages snapshot scheduler under `ops/pages-snapshot-scheduler`;
- static publishable `market-snapshot.json` runtime contract;
- React static snapshot loader/freshness path;
- browser-side duplicate authoritative recommendation engine/golden-vector path
  after equivalent server-side tests are preserved;
- static-deployment-only docs/CI references.

Preserve/adapt:

- C# Domain/Application/Analytics/Infrastructure projects;
- typed public GW2 gateway/request scheduler;
- finance and order-book logic/tests;
- reusable React accessibility/UI components/styles/tests;
- generic CI and secret-scanning protections.

## Acceptance criteria

- [ ] Active CI no longer builds/deploys GitHub Pages as application runtime.
- [ ] External Pages scheduler is removed from active source/build.
- [ ] React project still builds.
- [ ] C# solution still builds.
- [ ] Browser no longer owns a competing authoritative recommendation/fee formula.
- [ ] Proven financial/order-book/gateway tests are preserved or deliberately adapted.
- [ ] Obsolete static docs are removed or clearly historical.
- [ ] No account/local-host/SQLite feature is implemented yet.

## Validation

- Active .NET tests relevant to touched projects.
- Frontend build/tests.
- Workflow/script tests after CI cleanup.
- Diff review for accidental deletion of reusable core code/tests.
- Secret scan if workflow/ops files are touched.

## Non-goals

Local ASP.NET host, SQLite, API key, personal TP endpoints.

## Delivery and review

Functional summary must explain what runtime was retired and what reusable
capabilities were intentionally preserved and remain within the required 2-6
sentences. Before delivery, update `CURRENT.md` to TKT-M12-03 or an explicit
valid handoff. Fresh review required before merge.

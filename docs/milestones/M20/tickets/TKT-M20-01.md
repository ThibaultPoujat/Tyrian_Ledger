# TKT-M20-01 - Derive Personal Fill-Time and Capital-Turnover Intelligence

GitHub issue: #89

## Milestone

M20 - Personal Learning and Investments

## Goal

Learn which markets actually work for this account using stored order
observations/completed transactions without inventing timing precision the API
does not provide.

## Functional outcome

Where evidence is sufficient, the app can show approximate fill/holding
intervals, capital lock duration, realized profit/day, and turnover with sample
count/confidence.

## Dependencies

TKT-M14-02, TKT-M15-03, TKT-M18-02.

## Recommended Codex configuration

Risk class: **R3 (quantitative/personal evidence)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Metrics where inferable

- interval from first observed open order to confirmed completion window;
- approximate buy/sell fill duration;
- partial-fill behavior where source supports it;
- capital locked duration;
- realized profit/day/capital turns;
- sample count/confidence/recency.

## Acceptance criteria

- [ ] API timestamp/observation limitations explicitly documented.
- [ ] Polling interval is never mislabeled as exact fill timestamp.
- [ ] Order observation history is sufficient/reproducible for supported estimates.
- [ ] Exact-known, interval-censored/estimated, and unknown tests exist.
- [ ] Low sample size clearly labeled and cannot silently become strong evidence.

## Delivery and review

Functional summary explains what the app has learned from personal trading
speed. Fresh flagship XHigh quantitative review required.

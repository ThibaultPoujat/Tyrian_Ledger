# TKT-M20-02 - Integrate Personal Realized Performance into Market Ranking

GitHub issue: #90

## Milestone

M20 - Personal Learning and Investments

## Goal

Allow sufficiently sampled personal realized outcomes to improve explainable
ranking while generic market evidence remains primary for weak/no history.

## Functional outcome

Markets that repeatedly turn this user's capital well can gain ranking weight,
and attractive-looking markets with poor personal turnover can lose weight,
with the personal contribution visible and bounded.

## Dependencies

TKT-M19-02, TKT-M20-01.

## Recommended Codex configuration

Risk class: **R3 (recommendation/quantitative)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Personal evidence candidates

- realized ROI distribution;
- realized profit/day;
- capital turns/day;
- completion/fill success rate;
- typical holding interval;
- sample size/recency.

## Acceptance criteria

- [ ] Personal influence is zero/limited below explicit sufficiency threshold.
- [ ] Personal component is decomposable in score explanation.
- [ ] Poor turnover can lower ranking despite attractive snapshot ROI.
- [ ] Strong repeatable personal market can outrank higher-ROI slower market in regression vector.
- [ ] No-history, weak-history, stale-history, strong-history cases covered.
- [ ] No automatic rule/weight self-modification.

## Delivery and review

Functional summary explains how recommendations now use the user's own evidence.
Fresh flagship XHigh quantitative/financial review required.

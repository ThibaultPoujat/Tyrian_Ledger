# TKT-M21-02 - Implement Owned-Material Opportunity Cost and Crafting Economics

GitHub issue: #93

## Milestone

M21 - Crafting Intelligence

## Goal

Calculate crafting profit economically so owned tradable materials are never
mistaken for free inputs.

## Functional outcome

For a feasible craft, the user can see economic input cost, owned/bought/mixed
strategy, exact output fees, net proceeds, economic profit/ROI, and break-even
output price with uncertainty for bound/unknown inputs.

## Dependencies

TKT-M15-01, TKT-M21-01.

## Recommended Codex configuration

Risk class: **R3 (financial)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Requirements

For ingredients determine where possible:

- owned quantity;
- market replacement/acquisition cost;
- realizable opportunity value for owned tradable material;
- bound/non-sellable handling;
- mixed owned+purchased cost.

For output compute economic input cost, gross sale, exact fees, net proceeds,
profit, ROI, and break-even.

## Acceptance criteria

- [ ] Owned tradable materials contribute opportunity cost.
- [ ] Mixed owned/purchased inputs exact.
- [ ] Bound/unknown/unavailable-price states explicit.
- [ ] Owned, bought, mixed, bound, unavailable test vectors.
- [ ] Gross output price alone can never mark a craft profitable.
- [ ] Browser does not duplicate crafting financial formula.

## Validation

- Run independently derived owned, purchased, mixed, bound, unknown/unavailable,
  output-fee, break-even, quantity, rounding, and overflow vectors.
- Run canonical fee-policy tests and verify provisional fee status remains
  disclosed if VERIFY-013 is open.
- Verify frontend code only renders backend economics and contains no duplicate
  crafting financial formula.

## Non-goals

Recipe-path search, exhaustive optimization, automated crafting, or treating
owned tradable materials as free.

## Delivery and review

Functional summary explains how crafting now values owned resources fairly.
Keep it to the required 2-6 sentences. Before delivery, update `CURRENT.md` to
TKT-M21-03 or an explicit valid handoff. Fresh flagship XHigh financial review
required.

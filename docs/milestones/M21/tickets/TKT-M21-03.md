# TKT-M21-03 - Add Bounded Crafting-Path Analysis and Profitable-Craft UI

GitHub issue: #94

## Milestone

M21 - Crafting Intelligence

## Goal

Find practical profitable crafting paths without exhaustive/unbounded world
optimization.

## Functional outcome

The user can browse feasible craft opportunities, including multi-step paths,
input strategy, exact economics, truncation/unknowns, and output market
liquidity/history evidence.

## Dependencies

TKT-M19-01, TKT-M21-02.

## Recommended Codex configuration

Risk class: **R3 (financial/algorithmic)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Requirements

- Reuse/refine historical bounded recipe-graph design.
- Respect verified discipline/recipe availability.
- Cycle detection.
- Configurable depth/candidate limits.
- Memoize repeated subproblems.
- Compare purchase versus intermediate crafting using opportunity cost.
- Include output liquidity/history before calling margin actionable.
- Show unlock cost/payback where verified evidence permits.

## Acceptance criteria

- [ ] Simple, multi-step, alternative-path, cycle test vectors.
- [ ] Depth/candidate truncation explicitly reported.
- [ ] Mixed owned/purchased path economics consistent with TKT-M21-02.
- [ ] Results include net profit/ROI/input strategy/liquidity/history evidence.
- [ ] React can filter/sort/detail profitable crafts without recomputing financial truth.
- [ ] No exhaustive world optimization or automation.

## Validation

- Run simple, multi-step, alternative-path, cycle, depth/candidate truncation,
  memoization, mixed-input, and unavailable-evidence algorithm vectors.
- Run crafting economics plus output liquidity/history prerequisite suites.
- Run frontend component/accessibility and representative Playwright craft-
  research journeys; verify React does not recompute economics.

## Non-goals

Exhaustive world optimization, gameplay/crafting automation, or profitability
claims without output liquidity/history evidence.

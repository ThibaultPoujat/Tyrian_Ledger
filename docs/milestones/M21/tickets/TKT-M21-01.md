# TKT-M21-01 - Add Account Inventory, Material, and Crafting-Capability Ingestion

GitHub issue: #92

## Milestone

M21 - Crafting Intelligence

## Goal

Add only the verified read-only account data needed to evaluate crafting
feasibility and owned-material economics.

## Functional outcome

The application can know relevant owned material/inventory quantities, crafting
discipline capability, and recipe/unlock evidence available through verified
ArenaNet contracts without broad private-data overcollection.

## Dependencies

TKT-M13-02, TKT-M14-01.

## Recommended Codex configuration

Risk class: **R3 (security/private account data)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Requirements

Through typed authenticated gateway add verified reads needed for:

- relevant material storage/bank/inventory quantities;
- crafting disciplines/ratings;
- known recipe/account unlock evidence where API exposes it;
- recipe/item metadata required by later economics.

Persist normalized snapshots only as needed; avoid indefinite raw private
payload retention.

## Acceptance criteria

- [ ] Missing permissions disable only affected crafting features.
- [ ] Bound/non-tradable distinctions preserved where evidence exists.
- [ ] Account quantities scoped correctly.
- [ ] API key never reaches browser/SQLite/logs.
- [ ] Fixtures cover missing/partial/malformed data.
- [ ] External contract uncertainty tracked in VERIFY.

## Non-goals

Craft profit or recipe optimization.

## Delivery and review

Functional summary explains which crafting/account facts are now available.
Fresh flagship XHigh security/data review required.

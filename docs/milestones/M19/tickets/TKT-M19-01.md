# TKT-M19-01 - Implement Historical Spread, Volatility, and Liquidity Analytics

GitHub issue: #85

## Milestone

M19 - Core Recommendation Product

## Goal

Use locally collected observations to distinguish persistent tradable markets
from temporary snapshot spreads without pretending to forecast the future.

## Functional outcome

For sufficiently observed items, the app can show current and historical net
ROI behavior, spread/price volatility, liquidity stability, sample count, and
exact coverage for 7/30-day research.

## Dependencies

TKT-M18-02.

## Recommended Codex configuration

Risk class: **R3 (statistics/financial interpretation)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Metrics where sufficient

- current net ROI;
- 7-day median net ROI;
- 30-day median net ROI;
- percent observations meeting configured ROI thresholds (reference 15%/20%);
- buy/sell price volatility;
- spread volatility/persistence;
- median aggregate quantity/depth proxy;
- liquidity stability;
- observed range/drawdown where useful;
- sample count and coverage.

## Acceptance criteria

- [ ] Synthetic time-series tests reproduce independently known expected metrics.
- [ ] Insufficient window/sample returns explicit insufficient-data state.
- [ ] Missing/irregular observations handled deterministically.
- [ ] Output includes window/sample count/coverage.
- [ ] Money inputs remain integer copper; ratio/statistic precision semantics documented.
- [ ] No prediction/guarantee language.

## Non-goals

ML forecasting, inventing missing days, external historical-provider dependency.

## Delivery and review

Functional summary explains which historical questions can now be answered.
Fresh flagship XHigh quantitative review required.

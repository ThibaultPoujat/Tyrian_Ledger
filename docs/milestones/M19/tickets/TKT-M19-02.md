# TKT-M19-02 - Build the Explainable Opportunity Score and Anomaly Flags

GitHub issue: #86

## Milestone

M19 - Core Recommendation Product

## Goal

Replace profit-first beginner ranking with a deterministic transparent model that
can prefer repeatable liquid opportunities over spectacular but fragile spreads.

## Functional outcome

Every candidate receives decomposable opportunity components and risk/anomaly
flags, so the user can understand why a market ranks well or poorly instead of
trusting a hidden score.

## Dependencies

TKT-M17-02, TKT-M19-01.

## Recommended Codex configuration

Risk class: **R3 (recommendation/quantitative)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Conceptual components

- expected exact net ROI/absolute profit;
- current liquidity/depth;
- historical spread persistence;
- historical stability;
- personal evidence placeholder only when later sufficiently sampled;
- anomaly/risk penalties.

## Required flags

At minimum consider:

- extreme current ROI versus historical baseline;
- shallow best levels/price cliff;
- abrupt price spike/drop;
- abrupt depth/supply change;
- insufficient historical coverage;
- intended position excessive relative to market depth.

## Acceptance criteria

- [ ] Stable liquid 20-30% synthetic market can outrank 100% near-zero-liquidity market.
- [ ] Score is deterministic and exposes named component contributions/reasons.
- [ ] Insufficient data lowers confidence rather than inventing stability.
- [ ] Normalization/weight bounds prevent one accidental unbounded component domination.
- [ ] Pathological high-ROI/low-liquidity regression tests exist.
- [ ] No runtime LLM/opaque ML model.

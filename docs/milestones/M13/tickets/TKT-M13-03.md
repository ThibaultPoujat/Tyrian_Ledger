# TKT-M13-03 - Extend the Typed Gateway for Personal Trading Post Data

GitHub issue: #71

## Milestone

M13 - Local Runtime and Authenticated Read-Only Gateway

## Goal

Add typed read-only personal TP/account operations using the existing gateway
policy rather than feature-specific HTTP calls.

## Functional outcome

Application services can read current buys, current sells, completed buys,
completed sells, and minimal account scope through tested typed interfaces while
credentials remain confined to infrastructure.

## Dependencies

TKT-M13-02.

## Recommended Codex configuration

Risk class: **R3 (security/external data contract)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Requirements

Add verified typed operations for:

- current buy orders;
- current sell listings;
- completed buy history;
- completed sell history;
- minimal safe account identity/scope.

Preserve DTO/domain separation, scheduler/error conventions, auth injection at
infrastructure boundary, cancellation, and fixture/mocked tests.

## Acceptance criteria

- [ ] Application interfaces expose required personal TP reads without ArenaNet URL construction in feature code.
- [ ] Infrastructure implementation applies auth without returning/logging key.
- [ ] DTOs map into normalized application/domain records.
- [ ] Missing permissions/partial/invalid/transport/rate-limit cases map to stable failures.
- [ ] Tests use fixtures/mocked HTTP only.
- [ ] Endpoint/permission/timestamp assumptions are documented or in VERIFY.

## Validation

- Run typed-gateway fixture/mocked-HTTP tests for all listed personal TP reads,
  DTO mapping, cancellation, and stable error mapping.
- Run secret-redaction/non-disclosure tests and the local-host security
  integration suite.
- Review and update VERIFY-004, VERIFY-005, and VERIFY-008 where this ticket
  obtains or preserves endpoint/paging/schema/cache evidence.

## Non-goals

SQLite persistence, FIFO accounting, account UI beyond minimal safe status/debug
exposure required for tests.

Keep it to the required 2-6 sentences. Before delivery, update `CURRENT.md` to

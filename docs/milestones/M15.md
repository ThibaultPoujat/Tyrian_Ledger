# M15 - Trustworthy Accounting

## Goal

Make personal profit/cost-basis values financially authoritative enough to build
all later recommendations on top of them.

| Ticket | Scope | Depends on |

| [TKT-M15-03](M15/tickets/TKT-M15-03.md) | Realized/unrealized P&L, open cost basis, liquidation value, and 7/30/90-day stats. | M15-02 |

## Completion rule

Accounting rebuilds deterministically from stored evidence, unknown basis never
becomes free, realized/unrealized values remain separate, and R3 independent
review is clean.

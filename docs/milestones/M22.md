# M22 - Convenience, Hardening, and Evaluation

## Goal

Make Tyrian Ledger dependable for long-term daily use and measure whether the
recommendation system actually helps.

## Ticket sequence

| Ticket | Scope | Depends on |
|---|---|---|
| [TKT-M22-01](M22/tickets/TKT-M22-01.md) | Local actionable alerts with deterministic triggers/de-duplication. | M19-04, M20-03 |
| [TKT-M22-02](M22/tickets/TKT-M22-02.md) | Security/recovery/E2E/accessibility/local packaging hardening. | M18-03, M19-04 |
| [TKT-M22-03](M22/tickets/TKT-M22-03.md) | Version recommendation snapshots and evaluate observed outcomes/calibration. | M19-04, M20-02 |

## Completion rule

A clean machine can run/recover the local app, critical user journeys are
covered end-to-end, secret/data boundaries are re-audited, and recommendation
evaluation distinguishes observed trades from unexecuted suggestions.

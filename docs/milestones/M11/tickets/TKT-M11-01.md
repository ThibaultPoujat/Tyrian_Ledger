# TKT-M11-01 - External Pages Snapshot Scheduler

## Goal

Replace GitHub's best-effort native Pages schedule with a private Cloudflare
Worker Cron that dispatches the same trusted Pages workflow every 15 minutes.

## Dependencies

- TKT-M10-06 is merged; `VERIFY-014` remains resolved historical deployment
  evidence.

## Acceptance criteria

- Add a version-controlled TypeScript Cloudflare Worker whose only periodic
  behavior is the Cron `7,22,37,52 * * * *` dispatch of `pages.yml` on
  `develop`.
- The Worker has no public endpoint, no Guild Wars 2 or snapshot request, no
  browser role, and no credential, token, or response-body logging.
- The Worker obtains a short-lived GitHub App installation token from encrypted
  Cloudflare secrets. Its source locks the repository, workflow, and branch;
  the App is documented as repository-scoped, webhook-free, and Actions-write
  only.
- Remove native `schedule` from `pages.yml`, retain `push` and
  `workflow_dispatch`, and ensure the concurrency group does not interrupt a
  running trusted capture.
- Add Worker unit tests and a separate secret-free CI job. Update Pages workflow
  contract tests for the new trigger and concurrency policy.
- Create ADR-009, update security and operations documentation, add M11 to the
  milestone index, and add VERIFY-015 as unresolved rollout evidence.
- The owner prepares and, after merge, deploys/enables the Worker and records
  two consecutive successful Cron-dispatched Pages runs before VERIFY-015 is
  resolved. Codex does not create the App, provision secrets, configure
  Cloudflare, merge the PR, or enable the Worker.

## Required validation

- `npm --prefix ops/pages-snapshot-scheduler run check`
- `npm --prefix ops/pages-snapshot-scheduler test`
- `node --test .github/scripts/*.test.mjs`
- Existing .NET, frontend, Playwright, static-artifact, and production-build
  validation matrix.
- `gitleaks detect --source . --log-opts="--all" --redact --no-banner`
- `git diff --check` and targeted review of Worker, workflow, CI, and rollout
  documentation.

## Non-goals

- Deploying Cloudflare infrastructure, creating a GitHub App, setting secrets,
  changing GitHub Pages settings, or merging a PR.
- Reading a public snapshot, calling Guild Wars 2 from Cloudflare, or changing
  browser behavior, financial calculations, selector policy, or capture limits.

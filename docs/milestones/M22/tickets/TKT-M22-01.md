# TKT-M22-01 - Add Local Alerts for Actionable Market and Portfolio Conditions

GitHub issue: #95

## Milestone

M22 - Convenience, Hardening, and Evaluation

## Goal

Reduce repeated manual checking by surfacing local notifications from existing
deterministic rules without executing any trade.

## Functional outcome

The user can enable alerts for meaningful changes such as viable outbids,
economically invalid bids, watchlist threshold opportunities, investment target
levels, or portfolio risk breaches, without repeated duplicate spam.

## Dependencies

TKT-M19-04, TKT-M20-03.

## Recommended Codex configuration

Risk class: **R2**.

- Implementation: Terra High or Sol High.
- Review: fresh Sol High.

## Initial alert conditions

- watched market exceeds configured threshold;
- current buy is outbid but remains below max bid;
- current bid becomes economically invalid;
- investment target reached;
- cash reserve/concentration limit breached;
- material watched-position anomaly where existing evidence supports it.

## Acceptance criteria

- [ ] Alerts originate only from deterministic existing rule outputs.
- [ ] No alert executes/modifies TP order.
- [ ] Identical unchanged condition is de-duplicated.
- [ ] Enable/disable/threshold settings local and durable.
- [ ] Alert contains reason and intended manual action.
- [ ] Trigger/no-trigger/de-dup/recovery tests.

## Delivery and review

Functional summary describes which checking burden is reduced. Fresh review
required before merge.

# TKT-M22-03 - Record and Evaluate Recommendation Outcomes

GitHub issue: #97

## Milestone

M22 - Convenience, Hardening, and Evaluation

## Goal

Measure whether the deterministic recommendation system actually helps instead
of trusting design assumptions indefinitely.

## Functional outcome

The app can preserve what it recommended under a specific rules/config version
and compare applicable user-executed outcomes with modeled expectations, while
leaving unexecuted recommendations explicitly unobserved.

## Dependencies

TKT-M20-02, TKT-M22-02.

## Recommended Codex configuration

Risk class: **R3 (quantitative/evaluation)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Recommendation snapshot evidence

Store/version applicable:

- timestamp/item/action;
- score components/flags;
- max bid/suggested allocation;
- current/historical/personal evidence;
- configuration/rules version.

Evaluate where observed:

- realized versus modeled result;
- completion/turnover by recommendation class;
- low-liquidity/false-positive patterns;
- score calibration by bucket;
- defensible simple benchmarks.

## Acceptance criteria

- [ ] Old recommendation context remains reproducible after future rule changes.
- [ ] Observed user trades are distinguished from unexecuted suggestions.
- [ ] No counterfactual profit fabricated for trades never executed.
- [ ] Versioning and observed/unobserved distinction tested.
- [ ] Reports can identify weak strategies/components without automatically changing rules.
- [ ] Personal/private evaluation remains local-first.

## Validation

- Run versioning/migration, observed-versus-unobserved, executed-versus-
  unexecuted, rule/config replay, calibration bucket, benchmark, and privacy
  regression tests.
- Verify old recommendation snapshots remain reproducible after rule-version
  changes and no counterfactual profit is created.
- Run relevant recommendation/accounting/personal-ranking suites and report
  evaluation limitations for insufficient samples.

## Non-goals

Automatic rule/weight changes, fabricated counterfactuals, external sharing of
private outcomes, or claiming causal investment performance.

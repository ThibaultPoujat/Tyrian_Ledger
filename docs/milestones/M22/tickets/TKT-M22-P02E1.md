before a later ticket changes financial authority. Provide a bounded explicit
capture/replay harness, an independently justified evidence matrix and a proposed
supported correlation contract. This ticket does not relax production admission,
confirm physical actions, or promise coherence/instance identity.

   VERIFY-016/017 evidence; do not resolve them from docs or synthetic sequences.

   typed collector/gateway, scheduler and generation fence. No independent timer,
   key input field, raw URL construction, key changes or ArenaNet mutation. Capture

3. Use disposable local investigation data separated from production evidence.
   Keep normalized source clocks/coverage/binding/components and stable local
   aliases. No secret/raw authenticated payload/private name/account ID in logs,
   committed fixtures, PRs or prompts. Provide an export allowlist and tests;
   only synthetic/sanitized evidence may leave the private local workspace.
4. Replay delayed bag→bank, bank→bag, delivery→bag and craft input/output sequences,
   repeated IDs/slots, equipment/template copies, partial/missing coverage and
   out-of-order captures. A pure diagnostic result distinguishes observed facts,
   local user annotations and unresolved correlations. An annotation is never
   API evidence and cannot promote physical completeness.
5. Record candidate positive/negative matching requirements, competing explanations
   and whether upstream facts actually supply each requirement. Exact slot/item
   equality, unchanged second reads, elapsed cache windows, aggregate disappearance
   or recipe arithmetic alone cannot prove action/instance identity. Synthetic
   coherent frames test policy only. Live physical frames remain Partial and
   production single-location cap/protection floor/shadows remain unchanged.
6. If a configured key and owner-controlled manual in-game experiment are available,
   record bounded authenticated observations locally and publish only sanitized
   findings. Do not perform gameplay or ask for a key in chat. Without access,
   mark each actual row NOT OBSERVED and identify the exact missing experiment;
   harness delivery may pass but physical-proof exits remain BLOCKED.
7. End with a decision-ready proposal for P02E2: precisely supported slice,
   adequate evidence predicates, consumption uniqueness, failure/correction and
   restart behavior, or a finding that available APIs cannot support it. Any
   relaxation of financial/evidence authority requires a subsequent bounded

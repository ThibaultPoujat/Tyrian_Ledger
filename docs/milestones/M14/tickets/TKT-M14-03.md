# TKT-M14-03 - Add Local Backup, Restore, and Clear-Personal-Data Controls

GitHub issue: #74

## Milestone

M14 - Durable Personal Data

## Goal

Protect the user's accumulating local history and provide explicit control over
personal data before it becomes irreplaceable.

## Functional outcome

The user can create a safe local backup, validate/restore it through a guarded
path, and intentionally clear personal account data without accidental loss or
cloud upload.

## Dependencies

TKT-M14-02.

## Recommended Codex configuration

Risk class: **R3 (destructive/recovery)**.

- Implementation: Sol High preferred.
- Review: fresh flagship XHigh.

## Requirements

- Document database location.
- Safe timestamped backup operation.
- Restore validates schema/compatibility before replacement and protects current data on failure.
- Clear-personal-data requires explicit confirmation/guard.
- Distinguish personal account data from public market history where model supports it.
- No automatic cloud backup/upload.

## Acceptance criteria

- [ ] Representative populated DB can be backed up without corruption.
- [ ] Invalid/incompatible restore is rejected without losing current DB.
- [ ] Successful restore is testable/restart-safe.
- [ ] Clear operation cannot happen accidentally.
- [ ] User-level docs are understandable without SQLite expertise.
- [ ] Tests cover failure paths as well as happy path.

## Validation

- Run populated-database backup/restore round trips, invalid/incompatible
  restore, interrupted/failure, restart, and guarded-clear integration tests.
- Verify current data survives every rejected or failed restore.
- Run relevant migration/repository tests and review user documentation from a
  clean local setup.

## Non-goals

Cloud backup, scheduled backup service.

## Delivery and review

Functional summary explains how data can be recovered/cleared. Fresh flagship
XHigh destructive-data review required. Keep the summary to the required 2-6
sentences and, before delivery, update `CURRENT.md` to TKT-M15-01 or an explicit
valid handoff.

# TKT-M15-01 - Establish and Register the Canonical GW2 Trading Post Fee Policy

GitHub issue: #75

## Milestone

M15 - Trustworthy Accounting

## Goal

Turn the existing configurable fee engine into one canonical GW2 application
policy while retaining generic fee primitives, and make its external evidence
status unambiguous.

## Functional outcome

Every backend feature can use one exact, documented fee/rounding policy; React
and feature code no longer need assumptions such as `price * 0.85`. If external
rounding evidence remains insufficient, the app and docs consistently identify
fee-derived results as modeled/provisional rather than verified behavior.

## External evidence outcome - 2026-09-07

TKT-M15-01 records completion path **(b)**:

- ArenaNet's [Missing Gold](https://help.guildwars2.com/hc/en-us/articles/222384087-Missing-Gold)
  support article documents a non-refundable 5% listing fee charged when an
  item is posted, including when the listing is later cancelled, and a 10%
  exchange fee deducted after a sale.
- The support article links the official
  [Trading Post wiki page](https://wiki.guildwars2.com/wiki/Trading_Post), which
  documents a 1-copper minimum for each fee.
- Neither source defines how a fractional-copper fee is rounded. Unit tests
  cannot supply that missing external evidence.

VERIFY-013 therefore remains OPEN. The canonical application policy retains the
owner-approved independent round-up of each fee as an explicit provisional
model; every dependent result remains named modeled/provisional.
